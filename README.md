# Algorithmic CLI Modules & Programming Exercises

Interactive Node.js console utilities, input validation routines, and algorithmic problem sets developed using modern ES modules.

*Leia isto em [Português](README.pt-BR.md).*

---

## Overview

This repository hosts procedural programming modules, CLI terminal interaction scripts (via `readline-sync`), and structured exercise sets (`API23`, `API24`) illustrating core algorithmic logic, loop constructs, numerical transformations, and data structures.

---

## Setup & Running

```bash
# Install dependencies
npm install

# Run exercise scripts
node API23/<script_name>.js
node API24/<script_name>.js
```
