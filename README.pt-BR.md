# Módulos CLI e Exercícios de Algoritmos em Node.js

Utilitários de terminal, rotinas de validação de entrada de dados e listas de exercícios algorítmicos desenvolvidos em JavaScript (ES Modules).

[![License: ISC](https://img.shields.io/badge/License-ISC-blue.svg)](LICENSE)

*Read this in [English](README.md).*

---

## Visão Geral

O projeto reúne módulos de lógica procedural, scripts interativos via console (utilizando `readline-sync`) e exercícios das séries `API23` e `API24`, demonstrando estruturas de controle, laços de repetição, manipulação de vetores e processamento de dados em terminal.

---

## Instalação e Execução

```bash
# Instalar dependências
npm install

# Executar os scripts
node API23/<nome_do_script>.js
node API24/<nome_do_script>.js
```
